# PIN CRÍTICO · xgboost==2.1.4
# ------------------------------------------------------------------------------
# Las versiones de XGBoost >= 3.0 serializan el parámetro `base_score` como
# lista (p. ej. '[5E-1]') en lugar de como número real. El cargador de modelos
# de SHAP (XGBTreeModelLoader) intenta convertirlo con float() y aborta con
# ValueError, impidiendo construir TreeExplainer.
#
# La corrección ya está incorporada en el repositorio de SHAP, pero únicamente
# en versiones que exigen Python >= 3.11 (shap 0.50+) o >= 3.12 (shap 0.52+).
# En entornos con Python 3.10 la única solución estable es fijar la última
# versión de XGBoost anterior al cambio de serialización: la 2.1.4.
#
# Incidencias de referencia:
#   https://github.com/shap/shap/issues/4202
#   https://github.com/shap/shap/issues/4288
#
# Este pin NO afecta al rendimiento del modelo: los hiperparámetros, el
# algoritmo de entrenamiento y las predicciones son equivalentes.
# ------------------------------------------------------------------------------
